## About me

I build software across product ideas, protocols, interfaces and developer workflows.

I like projects that start as experiments but become useful: clean flows, readable systems, better docs and small details that make software feel good to use.

Right now I am exploring:

- Web3 apps, wallets, identity and proof layers
- Games and interactive product experiences
- Developer tools, packages and workflow experiments
- Testing, software quality and documentation
- New chains, protocols and app ideas

## Build style

<table>
  <tr>
    <td><b>Map</b></td>
    <td>Start with the user flow and the actual job the product should do.</td>
  </tr>
  <tr>
    <td><b>Build</b></td>
    <td>Ship a small working version before over-polishing the idea.</td>
  </tr>
  <tr>
    <td><b>Test</b></td>
    <td>Try the real path, find rough edges and fix what blocks usage.</td>
  </tr>
  <tr>
    <td><b>Document</b></td>
    <td>Write READMEs and notes that make the project easy to understand.</td>
  </tr>
  <tr>
    <td><b>Improve</b></td>
    <td>Iterate through focused changes instead of noisy rewrites.</td>
  </tr>
</table>
